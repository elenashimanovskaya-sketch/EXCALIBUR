## action_outline (7 шагов для writer)

1. **Объяснить механизм за 2 минуты:** UV → ROS → MMP → потеря коллагена; антиоксиданты + SPF — не «омоложение», а замедление фотостарения.
2. **Собрать утренний стек:** очищение → сыворотка с C (или C+E+феруловая) → увлажняющий крем → SPF 30–50 broad spectrum/PA++++.
3. **Разобрать 5 антиоксидантов по таблице:** для каждого — 2 продукта в тарелке + как искать в INCI + частота (ежедневно / через день для чувствительной кожи).
4. **Недельное меню без фанатизма:** 7 приёмов пищи с акцентом на C, E, полифенолы (не заменяет уход, дополняет).
5. **Вечерний контраст:** антиоксиданты утром; ретиноиды/пептиды — вечером (если уже в рутине; с осторожностью, без назначения).
6. **Чеклист ошибок:** «только БАД», «C без SPF», «ждать эффект за 3 дня», «смешивать все кислоты сразу», «игнорировать шею и руки».
7. **FAQ + CTA:** когда ждать результат (8–12 недель), чувствительная кожа, можно ли беременным — без медназначений; ссылка на diagnostika-kozhi и B33/B28/B25.

## FAQ (черновик для writer — ответы-действия)

| Вопрос | Краткий actionable ответ |
|--------|--------------------------|
| С какого возраста нужны антиоксиданты в уходе? | С **20–25 лет** — SPF + увлажнение; сыворотку с C можно добавить, когда кожа переносит; после **40** — усилить Q10 и полифенолы в рутине (источник трендов: yakrasivaya24.ru). |
| Можно ли только пить витамины вместо кремов? | **Нет** для витамина C: oral не насыщает кожу (PMC3673383). Еда + топика — дополняют друг друга. |
| Утро или вечер для витамина C? | **Утро** перед SPF — максимальная защита от дневного UV/городского стресса. |
| Через сколько ждать результат? | Оценивайте тон и сияние через **8–12 недель** ежедневного SPF + антиоксидантов; «за 3 дня» — маркетинг. |
| Чувствительная кожа — с чего начать? | С **стабильных производных C** (аскорбил глюкозид, SAP) или низкой концентрации; patch-test 48 ч; запрос Wordstat: 62 показа «для чувствительной кожи». |
| Можно ли смешивать C и ретинол? | **Не в один слой:** C утром, ретинол вечером; при раздражении — пропустить актив на 2–3 ночи. |
| Какие продукты в тарелке дадут быстрый «антиоксидантный» эффект? | Ягоды + зелёный чай + горсть орехов + цитрусовые/перец — **ежедневно**, без мегадоз БАД. |
