## Угол (utility-only)

Практический гайд для женщин 35–65: определить «сейчас» Вата/Пита/Капха по коже (связка с B26), выбрать из трёх базовых средств (кунжут, гхи, алоэ-гель/экстракт), провести 48-часовой тест комедогенности и собрать домашнюю смесь без забитых пор. Не каталог магазинов, не «что такое аюрведа».

**reader_outcome:** Читатель за один вечер составит таблицу «моя кожа сейчас → масло/пропорция → как наносить и смывать», проведёт патч-тест и получит рецепт лёгкой смеси на 3–5 дней (гхи + алоэ для сухой Ваты, алоэ + жожоба для Питы/жирной Капхи, кунжут точечно только на сухие зоны).

## action_outline

1. **Самодиагностика за 3 минуты** — по признакам кожи (сухость/покраснение/жирный блеск) отметить доминирующую дошу «сейчас»; при сомнении — квиз `/diagnostika-kozhi/`.
2. **Разделить продукты** — пищевое кунжутное/гхи (холодный отжим, без ароматизаторов) vs «масло алоэ» (экстракт в базе, не чистое масло) vs гель алоэ 99%+ для Питы.
3. **Проверить комедогенность** — патч-тест 48 ч на линии челюсти: 1–2 капли чистого продукта; фиксировать комедоны/зуд.
4. **Подобрать базу по доше** — Вата: тёплый кунжут или гхи (1–3 капли); Пitta: гель алоэ + 1 капля жожоба; Капха: жожоба/горчичное, кунжут и гхи только на сухие участки, не на Т-зону.
5. **Собрать смесь «за 2 минуты»** — Вата: ½ ч.л. гхи + 1 ч.л. гель алоэ; Пitta: 2 ч.л. гель алоэ + 3 капли жожоба; Капха: 1 ч.л. жожоба + 2 капли масла нима (при воспалениях).
6. **Техника нанесения** — на очищенную влажную кожу, похлопыванием, 5–10 мин лёгкий массаж по линиям лица; излишки через 15–20 мин убрать салфеткой.
7. **Режим на 7 дней** — вечерний уход 4–5 раз в неделю; утром только лёгкий гель/крем; при новых комедонах — откат на одну базу и повтор теста.
8. **Стоп-лист ошибок** — кокосовое и зародыши пшеницы на жирной коже; толстый слой гхи на всё лицо; «масло алоэ» вместо геля при покраснениях.
